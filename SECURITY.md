# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older versions may not receive security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the [GitHub private vulnerability reporting form](https://github.com/fearandesire/Pluto-Betting-Bot/security/advisories/new). Do not open a public issue, publish a proof of concept, or disclose details before maintainers have had an opportunity to investigate.

Include enough information to reproduce the problem safely, such as the affected version, relevant configuration, impact, and a minimal reproduction. Remove credentials, personal data, production identifiers, and other sensitive values from all reports and attachments.

Maintainers will acknowledge a report when possible, investigate its impact, and coordinate a fix and disclosure timeframe with the reporter.
